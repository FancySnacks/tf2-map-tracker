235 maps await you, play each one 18 times as each class on every team. This is might be just the biggest adventure!

### How to use

Please visit the website https://fancysnacks.github.io/tf2-map-tracker/ to use this map tracker.

#### Data
Data is saved locally on your device/browser, it will not work between different devices. To reset your progress you can press "Reset ALL Progress" button at the top, this will wipe out all of your map progress without recovery.

#### Do I have to complete maps in order?
No, the order is not forced because some maps aren't available all-year or are retired. You can complete maps in any order you want.

#### Mobile use not recommended
It doesn't work correctly on smartphones, unless you enable desktop mode view which makes it more manageable.
